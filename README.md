# Babylon.js Minecraft Clone

## Structure

- `main.js` - Babylon bootstrap
- `src/babylon/constants.js` - shared constants and performance flags
- `src/babylon/textures.js` - texture generation and cache
- `src/babylon/terrain.js` - terrain generation, chunk streaming, spawn math
- `src/babylon/game.js` - scene setup, controls, UI, main loop

## Run

Open `index.html` in a browser or serve the folder with a local HTTP server.
